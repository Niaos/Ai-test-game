算法手册 · 怎么写 decide(ctx)

① 先记住这 5 条规则看完就能写

  1. 入口函数必须叫 decide(ctx)，每 0.2 秒被自动调用一次，一局约调用 900 次。
  2. 每次调用最多发 4 条指令，第 5 条会被判非法。用 ctx.ordersLeft 看还剩几条。
  3. ctx.send(出发id, 目标id, 比例)：比例是从出发地当前驻军里抽多少，取值 (0,1]，如 0.6 = 抽六成。
  4. 部队飞行途中不参战，到达才结算：目标是自己的地 → 兵力相加（增援）；是敌方或中立 → 兵力相减，减成负数就易主。
  5. 占领全图或对方地块清零即胜；180 秒平分则按地块数判胜负。

最短能跑的算法只有 15 行 —— 点「覆盖编辑器」，然后按「应用并重开」就能看它打：

最小骨架攒够兵 → 找最弱的目标 → 抽 70% 过去 

          

        


        

          
② ctx 有哪些东西每轮都能读

          

            
字段类型说明

            
ctx.mine数组我的地块，元素是下面的「地块对象」。开局 3 块

            
ctx.enemies数组敌方地块

            
ctx.neutrals数组中立地块（owner 为 -1）

            
ctx.cells数组全图所有地块，选目标时遍历它

            
ctx.incoming数组正打向我的敌军，每项 {to, from, amount, eta}，eta 是还有几秒到达

            
ctx.ordersLeft数字本轮还能发几条指令，初始 4，send 成功就 -1

            
ctx.me数字我方编号（0 或 1，每局随机，别写死）

            
ctx.cols / rows数字棋盘列数 / 行数

            
ctx.time / tick数字已进行秒数 / 决策回合数

            
ctx.dist(a, b)函数两地块的格距（欧氏距离），判断远近用它

            
ctx.eta(a, b)函数从 a 飞到 b 要几秒（= 格距 × 0.3）

            
ctx.send(f, t, r)函数出兵。成功返回 true，非法返回 false 并记一次违规

            
ctx.rand()函数种子化随机数 [0,1)，同种子可复现，别用 Math.random

          

        


        

          
③ 地块对象长什么样

          

            
字段类型说明

            
id数字唯一编号，send 和 dist 都靠它

            
owner数字归属：等于 ctx.me 是我的，-1 是中立，其余是敌方

            
troops数字当前驻军（整数）

            
cap数字驻军上限：普通 110，城池 180

            
rate数字每秒产兵：普通 1.9，城池 3.4

            
type字符串'plain' 普通星球 / 'city' 城池

            
c / r数字列 / 行坐标，想自己算距离可以用

          

          
初始驻军会被游戏随机化（每格 20~90 左右），所以别硬编码阈值，按 troops 相对比较。

⑤ 报错了对号入座

          

            
decide is not a function函数必须叫 decide，而且不能定义在别的函数里面

            
xxx is not defined变量名写错；代码跑在沙箱里，document、window、fetch 都用不了

            
只能从自己的地块出兵send 的第一个参数用了敌方或中立地块的 id

            
ratio 必须在 (0,1] 内比例传了 0、负数、大于 1，或者传成了字符串

            
超出单次决策指令上限一轮 send 超过 4 次。循环里加 if (ctx.ordersLeft <= 0) break;

            
地块 xx 兵力不足（<2）该地块兵太少。出兵前判断 troops >= 3

            
算法异常：...运行时报错，具体信息会显示在编辑器下方的状态条里

          

        


        

          
⑥ 三个调试技巧

          
1. 边跑边看：console.log(ctx.time, ctx.mine.length) 的输出在浏览器控制台（F12）里，每 0.2 秒一条。

          
2. 先自检再开局：点面板上的「自检」，它会用当前棋盘和难度跑 8 局，报语法、非法指令、异常和胜率，比一局一局看快得多。

          
3. 改动要能对比：模拟是确定性的（固定步长 + 种子化随机），同一套代码配同一批种子结果完全一致，改一行就能看出差别。

          
4. 写不出思路就抄：点「范例」载入推荐算法（对内置 AI 胜率 99%+），先跑通再改，是上手最快的方式。
